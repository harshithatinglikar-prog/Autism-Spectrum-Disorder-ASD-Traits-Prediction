# Autism Spectrum Disorder (ASD) Traits Prediction

## Project Overview

This project focuses on analyzing autism screening data and identifying patterns related to Autism Spectrum Disorder (ASD) traits. I used Python and machine learning techniques to clean the data, explore important features, and build classification models.

## Objective

The main objective of this project is to understand the screening data and use machine learning models to predict ASD traits based on questionnaire responses and other available features.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Machine Learning Models

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Random Forest Classifier

## Project Steps

1. Imported and explored the dataset
2. Checked for missing values and duplicate records
3. Cleaned and preprocessed the data
4. Encoded categorical variables
5. Performed Exploratory Data Analysis (EDA)
6. Split the data into training and testing sets
7. Trained multiple classification models
8. Compared model performance using evaluation metrics
9. Analyzed the results and important features

## Dataset

The dataset contains autism screening questionnaire responses along with demographic and other relevant information. The questionnaire features were used to identify patterns associated with ASD traits.

## Results

The performance of the classification models was evaluated using metrics such as accuracy, precision, recall, F1-score, and confusion matrix. The results helped compare the models and understand how well they performed on the given dataset.

## Conclusion

This project helped me gain practical experience in data preprocessing, exploratory data analysis, feature engineering, and machine learning classification. It also helped me understand how screening data can be analyzed to identify meaningful patterns.

**Note:** This project is for educational and machine learning practice purposes and is not intended for medical diagnosis.
